# 📱 悬浮提词/提示助手 (FloatingPrompter)

专为**防切屏/防切后台/防分屏检测**设计的 Android 悬浮提示软件。

---

## 🎯 核心功能与亮点

1. **🛡️ 100% 防切屏检测（绝不丢焦点）**
   - 底层采用 `FLAG_NOT_FOCUSABLE` 与 `FLAG_LAYOUT_IN_SCREEN` 系统级悬浮技术。
   - 悬浮在屏幕最顶层时，底层的学院软件/考试软件**依然保持前台活跃焦点（`hasFocus = true` 且处于 `onResume`）**。
   - **完全不触发** `onPause()` / `onStop()` / 失去焦点事件，彻底避免“切屏 3 次被强制退出”的惩罚。

2. **📜 独立手势滑屏阅读**
   - 提示框内置 `ScrollView`，手指在文字区域可自由**上下滑动翻阅长文本**。
   - 底部提供 `⬆ 顶部` / `⬇ 底部` 一键直达快捷键。

3. **📌 真正常驻后台（不被系统杀死）**
   - 采用 Android 前台常驻服务（`ForegroundService` + `START_STICKY`）与系统通知栏守护。
   - 支持加入“电池优化白名单”，即使在多任务管理中清空后台，悬浮窗依然稳固停留在屏幕上。

4. **✨ 极致便捷的悬浮窗交互**
   - **任意拖拽**：按住顶部【⋮⋮】把手即可拖动到屏幕任何区域。
   - **一键最小化为悬浮球**：点击【—】化身为小巧半透明悬浮圆球（可贴边拖动），点击圆球即可瞬间展开。
   - **实时字号缩放**：随时点击【A+】 / 【A-】放大缩小字号（10sp ~ 26sp）。
   - **多档透明度切换**：支持点击【半透明】快速在 45%（极度隐形）、70%（半透）、95%（清晰）之间轮换。
   - **文本自动保存 & 实时同步**：主界面修改或粘贴文本后，悬浮窗内容即时自动同步更新。

## 🛠️ 如何编译与安装（Android Studio）

### 方式一：直接在 Android Studio 中打开
1. 打开 **Android Studio**。
2. 点击 **File -> Open...**，选择当前文件夹：`C:\Users\Lenovo\Desktop\test`。
3. 等待 Gradle 同步完成。
4. 连接手机（开启 USB 调试）或使用模拟器，点击顶部绿色的 **Run 'app' (▶)** 即可直接安装到手机。

### 方式二：生成安装包 APK
在 Android Studio 顶部菜单栏点击：
`Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`
打包完成后即可将生成的 `app-debug.apk` 发送到手机上直接安装。

## 📱 手机端使用指南

1. **授予权限**：
   - 首次打开应用，点击【🚀 启动常驻悬浮窗】，系统会跳转到权限页面，开启**“允许显示在其他应用上层”**（悬浮窗权限）。
   - （可选）点击下方【⚙️ 允许无限制后台运行】，避免手机深度睡眠时清理服务。
2. **输入/粘贴提示文本**：
   - 在主界面大输入框中输入或点击【📋 粘贴】放入你需要参考的提纲、公式或笔记。
3. **开启并使用**：
   - 点击【🚀 启动常驻悬浮窗】，屏幕上立即出现悬浮框。
   - 此时直接打开你的**学院软件**进行作答或学习。
   - 手指在悬浮框内**滑动查看文字**，也可以随时拖动位置或最小化为小球。
4. **关闭悬浮窗**：
   - 在悬浮窗右上角点击【✕】，或在下拉通知栏点击【关闭悬浮窗】，或返回本软件点击【⏹ 关闭悬浮窗】。

## 📂 项目结构概览

```text
app/src/main/
├── AndroidManifest.xml                        # 权限与前台服务声明
├── java/com/floating/prompter/
│   ├── MainActivity.kt                       # 主界面（输入、调节透明度、字号、启动）
│   ├── FloatingService.kt                    # 前台常驻保活服务（通知栏常驻 + START_STICKY）
│   ├── FloatingWindowManager.kt              # 悬浮窗核心逻辑（FLAG_NOT_FOCUSABLE、滑动、拖拽、悬浮球）
│   └── PreferencesManager.kt                 # 本地持久化存储（自动保存提示词、坐标与样式）
└── res/
    ├── layout/
    │   ├── activity_main.xml                 # 主控制台 UI
    │   ├── layout_floating_window.xml        # 悬浮文字窗 UI（支持滑动、拖拽、调节）
    │   └── layout_floating_bubble.xml        # 最小化悬浮球 UI
    └── values/
        ├── colors.xml
        ├── strings.xml
        └── themes.xml
```
